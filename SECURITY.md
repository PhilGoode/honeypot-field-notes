# Security Policy

Do not submit live malware, credentials, private keys, tokens, raw packet
captures, or unsanitized honeypot logs to this repository.

For a security concern involving the published tools, use GitHub's private
security-advisory feature after the repository is published. Do not include
production secrets or live malicious payloads in an issue.

The tools in this repository are read-only reporting aids. Operators remain
responsible for isolating sensors, blocking unnecessary egress, securing the
management plane, and complying with applicable law and provider policy.
